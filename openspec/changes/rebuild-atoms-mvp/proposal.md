# Proposal

## Why

我们已完成对 atoms.dev（多智能体 AI 建站平台）的功能逆向（见 `docs/00-逆向总览.md` 至 `docs/04-重建范围建议.md`），需要重建其**核心功能等价**的 demo 产品。对齐后的核心定义：**用户用自然语言描述产品 → agent 自由生成生产风格的全栈代码工程（前端 + 后端 + 数据持久化）→ 平台在沙箱中构建并自修复 → 每项目独立运行时一键上线公开 URL → 对话迭代后重建再上线**。周边能力（认证等）在 demo 阶段允许简化，但此核心闭环 MUST 完整落地。

## What Changes

- 新建 Next.js（App Router）+ React + TypeScript 单体应用（营销面与工作区以路由组隔离），内置反向代理
- **核心闭环（本变更重心，C 路线 + 自由生成）**：
  - **自由生成**：agent 从需求自由设计工程结构并产出多文件 Node/npm 全栈代码工程（不限定框架、目录结构、依赖；含前端、后端与数据持久化；以生产风格代码为目标）
  - **沙箱构建 + 自修复**：依赖安装与构建在隔离环境执行（容器优先，本机无 Docker 时进程级降级并明示）；构建/启动失败把错误回传 agent 自动修复，循环直至成功或达轮次上限；全程资源与并发受限
  - **独立运行时上线**：构建产物按项目独立运行（彼此及与宿主隔离），平台反代分配公开 URL（匿名可访问、不可猜测）；这就是用户「自己的产品」
  - **迭代**：后续需求修改工程 → 重建（含自修复）→ 再上线同一 URL
  - App Viewer：工作区沙箱 iframe 预览当前版本（代理到项目运行时，桌面/移动视口）
- 认证**简化**（demo 级）：邮箱即登录/注册（无 OAuth/验证码邮件），会话、安全回跳、私有路由守卫
- 营销面：首页转化区、「能构建什么」预览弹窗（演示项目 = 本平台预生成并构建好的工程）、定价页、六类内容页（种子精简）、i18n（zh/en）与 SEO 基础
- 生成侧为单 agent 单模型管线（多智能体编排与角色化叙事延后）
- **明确不做**（后续变更）：多智能体编排与批准流、Atoms Cloud 等价物的生产级托管（自定义域名、横向扩展、高可用）、Stripe 支付类集成、可视化编辑器、竞速模式、积分计费、Google OAuth/邮件验证码、视频生成、投放埋点
- 诚实边界：代码以生产风格生成为目标，但**运行隔离为 demo 级**（容器/进程隔离，非生产级多租户隔离）；此边界 MUST 在产品界面与 README 标注
- 复用约束：全新品牌与文案，**不**复用 atoms.dev 的品牌名、文案原文、图片、视频素材

## Capabilities

### New Capabilities

- `marketing-site`: 营销站骨架与首页转化行为——多语言路由、全局导航/页脚、语言切换持久化、首页 prompt 转化区与「开始」跳转、预览/克隆弹窗、定价页展示
- `content-catalog`: 数据驱动的内容目录——六类页面列表与详情、分类筛选、SSR 输出与 sitemap 收录
- `user-auth`: demo 级认证与会话——邮箱即登录/注册、redirect 安全回跳、会话与登出、私有路由守卫
- `workspace-projects`: 我的项目管理——列表、新建（携带初始需求）、删除（级联清理工程与运行时）、访问隔离
- `chat-build`: 构建对话控制面——`/chat/{id}` 消息流、消息触发生成-构建任务、过程与日志流式反馈、多轮迭代、历史持久化、失败重试
- `app-generation`: 全栈工程生成——自由生成多文件 Node/npm 工程（前端+后端+数据持久化）、文件协议落盘、基于上下文的迭代修改、以构建成功为界的版本化、失败保护
- `build-pipeline`: 工程构建编排——沙箱内安装依赖与构建、错误回传驱动的自修复循环（有轮次上限）、构建日志可观测、资源与并发约束、降级隔离模式
- `app-delivery`: 产品交付——每项目独立运行时托管、平台反代分配公开 URL（发布/更新/取消）、App Viewer 预览代理、交付入口

### Modified Capabilities

（无——greenfield 项目，尚无既有规格）

## Impact

- **代码**：`/home/admin/ivan/atoms` 下新建整个应用；现有 `docs/` 逆向文档不受影响
- **依赖**：Next.js、React、TypeScript、Tailwind CSS、shadcn/ui、next-intl、Prisma、Zod、http-proxy（内置反代）；LLM 用 OpenAI 兼容 SDK。**不引入** Auth.js/邮件服务
- **运行环境**：可选 Docker（有则容器隔离）；无 Docker 时以受限子进程运行并明示降级；构建与项目运行需要 Node 20 运行时与磁盘空间
- **环境变量**：`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`、`SESSION_SECRET`、（可选）`RUNTIME_ISOLATION=container|process`
- **数据**：宿主业务数据（用户/项目/消息/版本）存 SQLite；每项目工程与运行数据存独立目录（工程快照 + 项目自有 SQLite）
- **未受影响**：atoms.dev 本身（零写入）；本变更不含对外部署动作
