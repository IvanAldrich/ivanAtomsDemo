# Spec Delta

## Purpose

定义数据驱动的内容目录能力：模型、用例、竞品对比、提示词库、模板、发现六类页面由结构化数据源驱动渲染，为搜索流量与访客探索提供完整可抓取的内容页。

## ADDED Requirements

### Requirement: 六类内容页渲染
系统 MUST 为模型、用例、竞品对比、提示词库、模板、发现六类内容分别提供列表页与详情页路由，并以服务端渲染输出完整内容（匿名可访问、对爬虫可见）。

#### Scenario: 匿名访问内容详情页
- **WHEN** 未登录访客访问任一内容详情页 URL
- **THEN** 服务端返回完整渲染的页面内容，无需登录

#### Scenario: 不存在的内容条目
- **WHEN** 访问数据源中不存在的内容 slug
- **THEN** 系统返回 404 页面

### Requirement: 列表分类筛选
列表页 MUST 支持按分类筛选（模型页按供应商、提示词页按创作方向、模板页按品类），筛选状态 MUST 体现在 URL 参数中以便分享与回退。

#### Scenario: 按供应商筛选模型
- **WHEN** 用户在模型列表选择某供应商筛选
- **THEN** 列表仅显示该供应商模型，且 URL 含筛选参数，刷新后筛选保持

### Requirement: 内容数据驱动发布
内容页数据 MUST 来自结构化数据源。在数据源新增或修改条目后，对应新增/修改的页面 MUST 无需代码改动即可通过路由访问；标记为草稿的条目 MUST 不生成公开页面。

#### Scenario: 数据源新增条目即可访问
- **WHEN** 在数据源中新增一个已发布的用例条目
- **THEN** 其详情页路由可访问并出现在列表中

#### Scenario: 草稿条目不公开
- **WHEN** 某条目在数据源中被标记为草稿
- **THEN** 其详情路由返回 404 且不出现在列表与 sitemap

### Requirement: sitemap 与页面元信息
系统 MUST 为每种语言生成 sitemap 并收录全部已发布内容页。每个内容详情页 MUST 输出标题、描述与 Open Graph 元信息。

#### Scenario: sitemap 收录内容页
- **WHEN** 爬虫请求某语言的 sitemap
- **THEN** 返回的 sitemap 包含该语言下全部已发布内容页 URL

### Requirement: 发现页与模板页骨架
发现页 MUST 提供「最新」内容流；「已保存」标签对未登录用户 MUST 引导登录。模板页 MUST 提供品类分类导航（全部/落地页/游戏/完整网站）。

#### Scenario: 匿名浏览发现页
- **WHEN** 未登录用户打开发现页
- **THEN** 「最新」内容流可见，点击「已保存」时被引导登录

#### Scenario: 浏览模板分类
- **WHEN** 用户在模板页切换到「落地页」分类
- **THEN** 列表仅显示该分类模板
