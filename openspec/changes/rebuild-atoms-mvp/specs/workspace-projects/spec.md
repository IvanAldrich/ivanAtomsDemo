# Spec Delta

## Purpose

定义登录用户的项目管理能力：用户拥有互不可见的项目列表，可从营销站转化入口或工作区直接创建携带初始需求的项目，并可删除项目。

## ADDED Requirements

### Requirement: 我的项目列表
已登录用户 MUST 能查看自己的项目列表，每项 MUST 显示项目名称与最近更新时间，并按最近更新排序。列表 MUST 只包含该用户自己的项目。

#### Scenario: 查看项目列表
- **WHEN** 已登录用户打开我的项目页
- **THEN** 显示其全部项目，按最近更新时间倒序排列

#### Scenario: 无项目状态
- **WHEN** 没有任何项目的用户打开列表页
- **THEN** 显示空状态与创建项目的引导入口

### Requirement: 创建项目
用户 MUST 能创建新项目，创建时可携带来自首页转化区的初始需求文本。创建成功后 MUST 直接进入该项目的对话页。

#### Scenario: 从首页需求创建项目
- **WHEN** 已登录用户在首页提交需求
- **THEN** 系统创建以该需求为初始消息的新项目并进入其对话页

### Requirement: 删除项目
用户 MUST 能删除自己的项目，删除前 MUST 二次确认。删除 MUST 同时移除该项目关联的对话历史。

#### Scenario: 确认删除
- **WHEN** 用户对某项目点击删除并确认
- **THEN** 该项目从列表消失，其对话路由不再可访问

#### Scenario: 取消删除
- **WHEN** 用户在确认弹窗中取消
- **THEN** 项目保持不变

### Requirement: 项目访问隔离
用户 MUST 只能访问自己的项目。访问不存在的或他人的项目 MUST 得到 404 而非泄露其存在性。

#### Scenario: 访问他人项目
- **WHEN** 用户访问另一用户拥有的项目对话路由
- **THEN** 系统返回 404
