## 1. 前端

| 层 | 选型 | 证据 |

| 样式方案 | 原子化工具类（`text-20px lh-28px font-500 c-textNeutralWhite95` 形态，UnoCSS/Tailwind arbitrary-value 风格）+ scoped Vue CSS（data-v-xxx） | DOM class |

| 资产 CDN | `public-frontend-cos.metadl.com/nuxt-mgx/prod/assets/`（腾讯云 COS 自定义域） | 全部静态资源 |
| 部署标识 | buildId `4fd3624c-…`，buildAssetsDir `nuxt-mgx/prod/assets`（保留了前身 MGX 的工程名） | nuxt config |

帮助中心为**独立 Next.js App Router 应用**（`self.__next_f`、`helpcenter-display/prod` 部署目录）；router.atoms.dev 为独立 SPA（base-ui 组件、`/api/auth/oidc/start` 登录）。→ **多应用架构：主站 Nuxt、帮助中心 Next、Router 独立前端，各自独立部署共享 CDN 与品牌**。

## 2. 后端与 API 面（可观测部分）

```
atoms.dev
├── /api/*        主 API（业务接口，SSR 数据获取 + 客户端 XHR）
├── /nodeapi/*    Node 服务 API（用途分离，或为 BFF/内部接口）
├── /akgw/*       GA4/Ads 反向代理（自有域转发 google 收集端点，规避广告拦截）
├── /callback/*   第三方 OAuth/Webhook 回调（stripe/supabase/github/google-oauth/ga/mcp）
├── /auth/oidc    自身 OIDC 认证端点
└── /sitemap/*.xml  每语言站点地图（@nuxtjs/sitemap v7.6.0）
console-backend.deepwisdom.ai   SEO 内容平台 API（nuxt config seoPlatformApiUrl）
ingest.atoms.dev                自托管 PostHog（分析数据接收）
mgx-backend-cdn.metadl.com      Router 产品图 CDN
```

- 内容管理：营销页内容 + `atoms-cos.metadl.com/cms_medias/`（CMS 管理媒体）→ 营销内容由独立 SEO/CMS 平台管理，前端 SSR 渲染
- 认证：Google Sign-In（accounts.google.com/gsi/client）+ 邮箱验证码；OIDC 端点支持第三方接入（Router 用同一体系）
- 人机验证：Cloudflare Turnstile（sitekey 在运行时配置中）
- 应用托管：`app.atoms.dev` 泛子域，按 `{projectId}-{hash}--latest` 模式发布，支持自定义域名绑定

## 4. SEO 工程

- `nuxt-robots` 5.7.1：默认 `index, follow, max-image-preview:large`；私有路由全部 noindex
- **AI 爬虫白名单**：GPTBot、ClaudeBot、PerplexityBot、Google-Extended、ChatGPT-User、anthropic-ai、FacebookBot、Amazonbot 允许抓取公开页（AI 搜索优化）；Bytespider/CCBot 全站禁止
- 每语言独立 sitemap + sitemap_index；程序化页面（48 用例 + 29 对比 + 84 提示词 + 模型/agent 页）构成流量长尾
- OG/Twitter card 全套；canonical 由路由生成

## 5. 值得借鉴的工程决策（重建参考）

1. **营销站与产品分离**：营销 Nuxt SSR（SEO 优先），产品工作区独立路由（/dashboard、/chat），互不拖累
2. **内容平台化**：程序化 SEO 页由后端 CMS/API 驱动，前端只渲染，便于批量生成与多语言
3. **GA 反代**：自有域名代理统计端点，减少拦截损失
4. **每项目子域发布**：泛域名 + 项目隔离，发布即生效，支持 hash 版本与 `--latest` 别名
5. **组件级 CSS chunk**（PrimeVue 按需）+ 原子化工具类：营销页性能优先
6. **Turnstile + 邮箱验证码 + Google OAuth**：登录注册一体化，最小摩擦转化
