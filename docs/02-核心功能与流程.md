# 核心功能与流程

逆向方式：浏览器实测（转化流、预览/克隆交互、登录页）+ 帮助中心/营销页交叉验证。登录后工作区部分基于公开文档推断。

## 1. 用户旅程总览

```
访客（营销页）
   │ ①浏览用例/模板/对比/提示词页（程序化 SEO 承接搜索流量）
   │ ②首页 prompt 输入框写需求 → 点「开始」
   ▼
登录/注册（/login?redirect=…）
   │ Google OAuth 或 邮箱验证码；首次即注册
   ▼
工作区（/my-projects、/chat/*）
   │ ③描述需求 → AI 团队按角色协作（调研→规格→架构→构建）
   │ ④关键节点弹出「批准」请求（人始终拍板）
   │ ⑤对话式迭代修改；可视化编辑器微调布局组件
   │ ⑥竞速模式：多模型并行生成择优
   ▼
发布（Atoms Cloud）
   │ ⑦App Viewer 预览（desktop/mobile）
   │ ⑧Publish → 公开 URL（app.atoms.dev 子域）或自定义域名
   ▼
增长闭环
   ⑨SEO agent 自动优化自然流量；Ads agent 投放 Google Ads
   ⑩Stripe 收款；Data Analyst 看板分析；代码导出/GitHub 同步保留所有权
```

## 3. 关键交互流程实测记录

### 3.1 首页主转化流（实测）
1. 首页中央 textarea 填入需求（如「一个简单的待办事项应用」）
2. 点「开始」（span.start-button，位于 .prompt-footer）→ 前端携带 redirect 跳转 `/zh/login?redirect=/zh`
3. 登录页：Google OAuth 按钮（gsi client）或邮箱 + 「继续」；注册登录合一；服务条款链接在按钮下方

### 3.2 模板预览/克隆流（实测）
1. 首页「Atoms 能构建什么？」区点品类按钮（如 SaaS 落地页）
2. 打开 `role=dialog` 模态（data-testid=home-v13-build-preview-modal，PrimeVue 组件）：标题 + 「克隆」+「关闭」
3. 内容为 iframe，src 指向该演示项目的部署子域：`https://{projectId}-{hash}--latest.app.atoms.dev/`
4. 「克隆」= 将该项目复制为用户自己的新项目（未登录会引导登录）

### 3.3 发布流（文档交叉验证）
1. 项目在 /chat 中构建完成
2. App Viewer 预览（desktop/mobile 两个尺寸）
3. Publish → 生成公开 URL（项目子域）或绑定自定义域名
4. Share → 导出文件 / 设置协作者权限 / 复制分享链接
5. 后续修改 → 预览 → 再发布（覆盖更新）

### 3.4 演示数据流（模板/发现/用例内容）
- 用例、对比、提示词、模型、agent 页：**SSR 输出完整内容**（SEO 需要，内容大概率来自 SEO 平台后端 console-backend.deepwisdom.ai + CMS 媒体库 atoms-cos.metadl.com/cms_medias）
- 模板/发现列表页：SSR 只出骨架，列表数据客户端加载（匿名当前为空）；发现项目详情页 SSR 完整输出（被 sitemap 收录）

## 4. 与竞品的差异化卖点（对比页提炼）

1. **多智能体团队** vs 单一聊天机器人（v0/Lovable 仅前端生成）
2. **端到端全栈交付**（后端、数据库、支付、部署）vs 代码片段/静态原型
3. **增长内建**（SEO + 广告 + 分析 agent）vs 只管构建
4. **代码导出 + GitHub 同步**（无锁定）vs 平台锁定
5. 声称替代 15+ 工具、240+ 小时 → 8 小时交付 v1
