## 1. 产品是什么

**Atoms（前身 MGX）** 是 Foundation Agents / DeepWisdom（MetaGPT 开源团队）推出的**多智能体「AI 员工团队」网站/应用构建平台**。一句话定位：*把想法变成可销售的产品 —— AI 员工用于验证想法、构建产品并获取客户，几分钟内完成，无需编码*（"Vibe Coding" → "Vibe Business"）。

核心心智模型：**用一支虚拟软件公司替代真实外包团队**。8 个拟人化 AI Agent 模拟完整产品团队分工，用户像 CEO 一样下需求、做审批。

## 5. 关键转化与交互机制

- **主转化流**：首页大 prompt 输入框 →「开始」→ `/zh/login?redirect=/zh`（Google OAuth + 邮箱验证码登录）→ 工作区
- **预览/克隆**：「预览 X」按钮 → 模态框（标题 + 克隆 + 关闭）+ iframe 实时加载演示项目；「克隆」把模板复制为自己的项目（用例页称 Remix）
- **发布流**：项目对话构建 → App Viewer 预览（desktop/mobile）→ Publish（公开 URL + 自定义域名）；Share（导出文件/权限管理）
- **竞速模式（Race Mode）**：同一 prompt 在多个模型并行生成，用户择优

## 6. 规模与增长打法

- 21 个语言站点（/zh、/en、/ja…各含独立 sitemap），hreflang 全覆盖
- **程序化 SEO**：48 个用例落地页 + 29 个竞品对比页（vs v0/Lovable/Replit/Bubble/Wix/Manus…）+ 84 条 Seedance 提示词页 + 模型详情页
- 社区「发现」页收录用户项目（结构化 AI 生成介绍页 + 克隆入口）
- 重投放栈：Google Ads×3、GA4×2（经自有 /akgw 反代防拦截）、Bing UET、FB Pixel、TikTok/Reddit/LinkedIn/Yahoo、Customer.io 邮件
- 对 AI 爬虫（GPTBot/ClaudeBot/PerplexityBot…）主动开放索引（除 API 路径）
- 背书：170+ 国家、1M+ 社区构建者、MetaGPT 16.8 万 GitHub star、约 30 篇顶会论文
