## 阶段一：营销站 MVP（本次落地重点）

对等复刻公开站功能，技术选型可与原站不同（原站 Nuxt 3；重建建议按团队熟悉度选 Next.js 或 Nuxt 均可）。

| 模块 | 范围 | 验收标准 |
|---|---|---|
| 首页 | 促销 banner（可关闭）、prompt 输入区（hero）、「能构建什么」6 卡片、信任背书区、agent 团队展示（8 位）、功能矩阵、用户故事、定价区块、FAQ 折叠 | 首屏 LCP 达标；所有区块内容可用后台/配置驱动 |
| 预览弹窗 | 点击卡片 → modal + iframe 演示 + 克隆按钮 | 演示项目按 `{projectId}-{hash}--latest` 子域模式托管可复用 |
| 登录/注册 | Google OAuth + 邮箱验证码双通道，登录注册合一，redirect 回跳，条款确认 | 未登录点「开始」→ /login?redirect=… |
| 定价页 | 免费/Pro/Max 三档、月/年切换、积分档位表、FAQ | 数据配置化 |
| 内容型页面 | 模型目录（筛选）、用例落地页（模板化）、对比页（模板化）、提示词库（分类+详情）、agent 详情页 | 同一页面模板 + 数据文件驱动，批量生成 |
| 发现/模板 | 列表骨架 + 分类 tab；项目详情页模板（概览/功能/适合谁/场景/FAQ/创作者/克隆） | 匿名可浏览 |
| i18n | 至少 zh/en 双语言，路由前缀 + hreflang + 每语言 sitemap | 切换持久化 |
| SEO | robots（公开/私有分组、AI 爬虫白名单）、sitemap、OG/结构化数据 | Lighthouse SEO ≥ 95 |
| 基础埋点 | 页面 PV + 转化事件（开始点击、注册、克隆） | 事件可查询 |

**明确延后**：投放像素矩阵（GA 反代、多平台 pixel）、Customer.io、探索者/联盟计划、移动/桌面 app 分发页、博客。

## 阶段二：产品工作区（需要登录态与后端能力）

| 模块 | 范围 |
|---|---|
| 我的项目 | 列表/新建/删除 |
| 项目对话 | /chat/{id}：prompt → AI 执行流式反馈（MVP 可先接单模型/单 agent） |
| 多智能体编排 | 8 角色工作流（调研→规格→架构→构建），关键节点人工批准；竞速模式=多模型并行对比 |
| 可视化编辑器 | 生成结果的区块/组件级微调 |
| Atoms Cloud 等价物 | 应用托管（每项目子域发布）、数据库、认证、Stripe 收款 |

| 发布/分享 | Publish → 公开 URL/自定义域名；Share → 权限/导出 |
| 积分计费 | 每日/订阅/奖励积分按序消耗，套餐升降级规则 |

## 关键实现决策（提案时需确认）

1. **技术栈**：营销站 SSR 框架（Next.js / Nuxt / Astro）；建议与工作区前端统一或分离
2. **部署形态**：自有服务器 / Qoder Sites / 云；影响「每项目子域发布」的泛域名方案
3. **内容管理**：营销页内容用本地数据文件（MVP）还是接 CMS（后期）
4. **AI 能力来源**：重建工作区时模型接入走哪个网关（直接厂商 API / OpenRouter / 自建）
5. **品牌与素材**：全新品牌名与文案（逆向文档中的文案仅作结构参考，不直接复用）
