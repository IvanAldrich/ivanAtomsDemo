# 信息架构与路由清单

来源：zh sitemap（117 个 URL，完整清单见 [assets/sitemap-zh-urls.txt](assets/sitemap-zh-urls.txt)）、运行时 nuxt-robots 配置（见 [assets/nuxt-config.json](assets/nuxt-config.json)）。

## 1. 顶层信息架构（页脚四组导航）

```
atoms.dev/{locale}
├── 产品
│   ├── /pricing            定价
│   ├── /ai-agents          AI Agents 总览（8 个 agent，各含详情子页）
│   ├── /models             模型目录（按供应商/任务筛选）
│   ├── /tools              AI 工具（当前为占位空页「未找到工具」）
│   └── help.atoms.dev/zh   帮助中心（外链，Next.js 独立站）
├── 资源
│   ├── router.atoms.dev    Atoms Router（外链，独立产品）
│   ├── /templates          模板库（分类：全部/落地页/游戏/完整网站；匿名状态列表为空，客户端渲染）
│   ├── /discover           发现（社区项目广场；标签：最新/已保存）
│   ├── /usecases           用例（48 个程序化落地页）
│   ├── /comparison         比较（29 个竞品对比页）
│   ├── /blog               博客（英文）
│   └── GitHub(MetaGPT)
├── 公司
│   ├── /about              关于我们
│   ├── /join               加入我们
│   ├── MetaGPT / OpenManus / Foundation Agents（外链）
│   └── /privacy-policy、/terms-of-service
└── 社区
    ├── /explorer           探索者计划（+ /explorer/apply 申请页）
    └── X / LinkedIn / Discord / Reddit
```

顶部另有：`Menu`（移动端）、`提示词` 折叠区（→ /prompts/seedance-2.5、/prompts/seedance-2.0）、`登录`、`注册`、语言切换（21 语言 combobox）。

## 4. API 与回调路由

```
/api/*         主 API（对 AI 爬虫禁抓）
/nodeapi/*     Node 服务 API
/auth/oidc     OIDC 认证入口
/oauth/google  Google OAuth
/callback/{stripe|supabase|github|google-oauth|google-analytics-account|mcp/*}  集成回调
/akgw/…        GA4 反向代理（营销自建，防广告拦截）
```

回调路由证明的**集成能力面**：Stripe（支付）、Supabase（数据库）、GitHub（代码同步）、Google OAuth（登录）、Google Analytics（数据接入）、**MCP**（Model Context Protocol 工具接入）。

## 5. 用户应用托管域

- 演示/已发布应用：`https://{projectId}-{hash}--latest.app.atoms.dev/`（例：`1003904-c7322c...--latest.app.atoms.dev`）
- 自定义域名绑定（Publish 时配置）
- 发布产物支持移动/桌面预览与下载（/app-preview、/app-download）

## 6. i18n 结构

- 21 语言：zh、zh-TW、en、ja、ko、de、fr、es、it、nl、pl、pt-BR、ru、sv、th、tr、vi、id、ar、he、fa
- 路由模式：`/{locale}/path`（zh 默认根路径）；每语言独立 sitemap：`/sitemap/{locale}.xml`
- hreflang + OG 多语言 meta 全覆盖；帮助中心语言切换含 ไทย/עברית/فارسی
